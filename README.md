# 🛒 Telegram-бот: Магазин цифровых товаров с оплатой через YooKassa

Асинхронный бот на `python-telegram-bot` 20.x для продажи цифровых товаров (ключи, коды, услуги). Включает админ-панель для управления товарами и интеграцию с YooKassa для приёма платежей.

## Возможности
- 🛍 Каталог товаров с inline-кнопками «Купить»
- 💳 Оплата через YooKassa (тестовый/боевой режим)
- 🔐 Админ-панель: добавление, просмотр и удаление товаров
- 📦 Хранение данных в SQLite

## Стек
- Python 3.10+
- python-telegram-bot 20.x
- YooKassa API
- python-dotenv

## Быстрый старт
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` и заполните своими данными (токен бота, ключи ЮKassa)
4. Запустите бота: `python main.py`

## Структура проекта
- `main.py` — точка входа
- `config.py` — загрузка конфигурации из `.env`
- `db.py` — работа с базой данных (создание таблиц, CRUD-операции)
- `handlers.py` — все обработчики команд (start, shop, admin, add, items, покупка)
- `payment.py` — создание платежей через YooKassa
